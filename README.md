# 工数打刻(スマホ単体版)

Pixel 10 の Chrome だけで動く工数記録アプリ。サーバー不要。
NFCカードをかざして工程の開始・終了・休憩を打刻し、端末内に保存して集計する。

## ファイル

- `index.html` — アプリ本体(打刻・集計・記録修正・データ書き出し)
- `sw.js` — オフライン動作用(圏外でも起動できる)
- `manifest.webmanifest` / `icon.png` — ホーム画面アプリ化用

## セットアップ(15分・1回だけ)

Web NFC は HTTPS 必須のため、静的ホスティングに置く。GitHub Pages が無料で確実。
スマホのブラウザだけでも作業できる。

1. GitHub でリポジトリを新規作成(Public)
2. `index.html` `sw.js` `manifest.webmanifest` `icon.png` の4つをアップロード
3. Settings → Pages → Source を `main` / `(root)` にして保存
4. 数分後に出る `https://<ユーザー名>.github.io/<リポジトリ名>/` を Chrome で開く
5. メニュー →「アプリをインストール」または「ホーム画面に追加」
6. 端末の設定で NFC を ON にする

以後はホーム画面のアイコンから起動。圏外・機内モードでも動く。

※ 公開リポジトリだがアプリのコードだけで、打刻データは一切アップロードされない
   (データはスマホの中にのみ保存される)。

## カード

- 推奨: **NTAG213 / NTAG215**(スマホとの相性が良い)
- 工程ごとに1枚 + 休憩カード1枚 + 予備
- 登録は不要。**未登録カードをかざすと名前入力フォームが出る**ので、その場で
  名前と種別(工程/休憩)をつけるだけ

## 打刻ルール

| 操作 | 意味 |
| --- | --- |
| 工程カード | その工程を開始(別工程が動いていれば自動で切替) |
| 同じ工程カードを再度 | その工程を終了 |
| 休憩カード | 休憩の開始/終了(休憩時間は集計から控除) |
| 休憩中に同じ工程カード | 休憩終了して作業再開 |

- 起動後に「読み取り開始」を1回押す(Chromeの仕様でボタン起点が必須)
- 8秒以内の同じカードの連続読み取りは無視される
- カードが手元にない時は「カードなしで打刻」から選択して打刻できる

## 画面

- **打刻** — 現在の工程と経過時間。作業中は緑、休憩中は琥珀色
- **集計** — 日別・工程別の正味工数(休憩控除後)と工程別合計。7/14/31日切替。
  終了打刻のないセッションは最上部に赤で表示される
- **記録** — 打刻の削除・任意時刻への追加(打刻忘れの補正)、カード名の変更
- **データ** — CSV書き出し(Excel可)、バックアップの保存と復元

## 注意

データはこのスマホの中だけにある。**Chromeのサイトデータを削除すると記録も消える。**
週に1度「データ」タブからバックアップを保存し、ドライブ等に置いておくこと。
記録内容は「時刻 × カードUID」のみで、個人を特定する情報は保持しない。
